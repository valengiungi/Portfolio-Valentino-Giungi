# Portfolio - Valentino Giungi

Sitio web personal / portfolio profesional de Valentino Giungi, desarrollado como una landing page de una sola página (single page) en HTML, CSS y JavaScript.

## Descripción

Este proyecto presenta de forma clara el perfil profesional, experiencia, stack tecnológico, proyectos destacados y canales de contacto.

Incluye:
- Sección de presentación (hero)
- Sobre mí
- Experiencia laboral
- Habilidades técnicas
- Proyectos
- Contacto

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

## Estructura del proyecto

- `index.html`: contiene la estructura, estilos y scripts del sitio.

## Ejecución en local

Como es un sitio estático, podés abrir `index.html` directamente en el navegador o levantar un servidor local.

Ejemplo con Node.js:

```bash
npx --yes serve -l 8080
```

Luego abrí:

`http://localhost:8080`

## Despliegue

El proyecto puede desplegarse fácilmente en plataformas como Vercel, Netlify o GitHub Pages.
